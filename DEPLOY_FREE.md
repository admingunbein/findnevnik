# Бесплатная публикация PWA

Для установки PWA на iPhone нужен обычный HTTPS-адрес. Само приложение не требует сервера или базы данных: хостинг раздаёт только статические файлы, а расходы остаются на iPhone.

## Вариант 1 — GitHub Pages

1. Создай бесплатный аккаунт GitHub, если его ещё нет.
2. Создай новый репозиторий, например `findnevnik`.
3. Загрузи в корень репозитория все файлы из этой папки, включая папку `icons`.
4. В настройках репозитория открой раздел Pages и включи публикацию из основной ветки.
5. GitHub выдаст HTTPS-адрес вида `https://<username>.github.io/findnevnik/`.
6. Открой этот адрес на iPhone в Safari → «Поделиться» → «На экран “Домой”».

## Вариант 2 — любой другой статический HTTPS-хостинг

Подойдёт любой сервис, который публикует папку со статическими HTML/CSS/JS-файлами по HTTPS. Серверный код не требуется.

## После обновления приложения

Если меняешь код после публикации, увеличь версию `CACHE_NAME` в `sw.js`, например:

```js
const CACHE_NAME = 'findnevnik-pwa-v1.0.1';
```

После этого открой PWA при наличии интернета, чтобы iPhone получил обновлённые файлы.
