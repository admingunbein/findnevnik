# FINДНЕВНИК PWA v1

Локальное PWA-приложение для iPhone. Серверная база, аккаунт, Telegram, VPN и синхронизация не нужны.

## Что уже есть

- ЕДА / РАЗВЛЕЧЕНИЯ / ПОДПИСКИ / ШОПИНГ / БЫТ / ДРУГОЕ.
- Быстрое добавление расходов.
- Редактирование и удаление любой операции.
- Отмена последнего ручного расхода.
- КОМ для еды: 1 400 ₽ в день, 13% налог с покрытой части, превышение лимита остаётся расходом.
- Быстрый ввод: `350 ком`, `350 ком 16.10`, `350 ком 16.10.2026`, `350 ком 16.10 обед`.
- Если дата в быстром вводе не указана, используется текущая дата телефона.
- Отчёт по месяцам с корректным ИТОГО после компенсации.
- Подробный отчёт по каждой операции.
- История с фильтрами: категория, месяц, диапазон дат, КОМ, комментарий, мин/макс сумма.
- Регулярные подписки. Пропущенные списания создаются при следующем открытии приложения.
- Экспорт CSV для Excel.
- Полный бэкап/восстановление JSON.
- IndexedDB: данные хранятся локально на устройстве.
- Service Worker: после первого открытия приложение работает офлайн.

## Как запустить на компьютере для проверки

PWA и Service Worker требуют HTTP/HTTPS. Не открывай `index.html` двойным кликом как `file://`.

В папке приложения запусти:

```powershell
py -m http.server 8080
```

Затем открой:

```text
http://localhost:8080
```

## Как поставить на iPhone

Сначала папку нужно разместить на любом статическом HTTPS-хостинге. После этого:

1. Открыть адрес приложения именно в Safari.
2. Нажать «Поделиться».
3. Выбрать «На экран “Домой”».
4. Запустить FINДНЕВНИК с появившейся иконки.
5. После первого успешного открытия основные функции работают без интернета.

## Важное про данные

Данные не уходят в облако. Поэтому периодически делай `Ещё → Резервная копия JSON` и сохраняй файл в «Файлы»/iCloud Drive. Если iOS очистит данные сайта, удалить PWA или потерять телефон без бэкапа, локальная история может быть потеряна.

## Обновления

При замене файлов на хостинге увеличь версию `CACHE_NAME` в `sw.js` (например, `v1.0.1`), чтобы iPhone получил новую версию приложения.
